How to create a token
  1. Open github.com/settings/personal-access-tokens/new
  2. Name: site admin, Expiration: 1 year (or no expiration)
  3. Repository access → Only select repositories → 4sgarov.com
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate, copy the token and paste it above
